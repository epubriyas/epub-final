# Manual theme selection

The time-based theme schedule has been removed. New visitors default to Light. Desktop and mobile controls offer Light and Dark, and the selected theme persists across reloads and synchronizes across tabs.

Former Automatic preferences fall back to Light. The head bootstrap still applies saved manual preferences before page content renders, with cookies as a fallback when local storage is blocked.

There are no theme timers or theme updates triggered by time, focus, or visibility changes.
